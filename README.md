# FARM Project Management

## Getting Started

### Requirements

- Dart: 3.9.0 or newer
- Flutter SDK: 3.35.1 or newer
- Melos: 6.2.0
- CocoaPods: 1.16.2

### Config and run app

- cd to root folder of project
- Run `flutter pub get`
- Run `make build_all`
- Run Debug Run for VSCode
